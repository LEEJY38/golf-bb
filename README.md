# Golf BB — GitHub Pages

This folder is the public, static frontend for Golf BB.

- Guests can view the live score without signing in.
- Two authorized scorers can sign in and update only their assigned flight.
- Hole scores and PAR values are stored by the existing Golf BB cloud backend.
- Passwords and server secrets are not included in this repository.

The expected public address is:

`https://leejy38.github.io/golf-bb/`

GitHub Pages should publish this folder's contents from the repository root.
